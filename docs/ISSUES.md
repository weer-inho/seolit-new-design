# Известные проблемы

Проверено 28.10.2026 в Chromium на ширине 1440 и 390 px. Причины найдены, исправления — в [prompts/01](prompts/01-motion-and-scroll.md).

Статусы: ✅ исправлено · 🔧 открыто.

## 1. ✅ Слово «сразу» в плашке не меняется, иконки соцсетей «не долетают»
**Симптом.** На первом экране слово не сменяется на «по расписанию» и дальше. На экране орбиты пост не летит в соцсети, орбита стоит.

**Причина.** В системе включено «уменьшение движения»: в Windows это Параметры → Специальные возможности → Визуальные эффекты → «Эффекты анимации» выключены.
Браузер сообщает сайту `prefers-reduced-motion: reduce`, и сайт по правилу из CLAUDE.md останавливает **все** автоанимации (флаг `reduced` в `js/main.js`).
В CSS при этом все `animation-duration` сжимаются до 0,001 мс.

Проверка: без настройки слово меняется каждые 2,6 с, с настройкой — стоит на «сразу».

**Что решили.** Полностью замирающий сайт выглядит сломанным, а это ровно та проблема, которую решаем («работает ли сервис?»).
При `reduce` убираем только крупное движение (параллакс, полёты, вращения, переезды), а смену состояний оставляем — плавным проявлением на месте.
Подробно — в SPEC.md, раздел «Уменьшение движения».

**Исправлено 28.10.2026.** Флаг `reduced` разделён на `still` (крупное движение) и `fade` (смена состояний проявлением). CSS-блок reduce больше не обнуляет все анимации: движущие выключены, остальные заменены opacity-версиями. Проверено в Chromium с `reducedMotion: 'reduce'` на 1440 и 390 px: слово меняется, карточки ходят по колонкам, лента и график обновляются, ничего не летает и не крутится.

## 2. ✅ Прокрутка не доводит до следующего экрана
**Симптом.** Колесо прокручивает страницу на 120 px, следующий экран не «прыгает» на место.

**Причина.** `scroll-snap-type: y proximity` доводит только когда прокрутка закончилась рядом с началом экрана.
Первый экран выше окна (1251 px при окне 900 px), поэтому рядом с краем пользователь не оказывается.

**Что решили.** Пошаговое листание: одно движение колеса / свайп / PageDown = следующий экран. Экраны выше окна листаются внутри себя обычным образом, а затем переход на следующий. Подробно — SPEC.md, раздел «Прокрутка».

**Исправлено 28.10.2026.** Модуль `pager` в `js/main.js`, CSS-доводка отключается классом `html.paged`. Проверено: колесо, имитация тачпада с инерцией (70 событий → ровно один экран), PageDown/PageUp/стрелки, точки, свайпы на 390 px, мяч песочницы и орбита пальцем не листают, окно 560 px — обычная прокрутка.

## 3. ✅ В бегущей строке нет иконок соцсетей
**Симптом.** Под доской на первом экране только названия.

**Что решили.** Перед каждым названием — цветная плашка из `NETS` (класс `.chip`), как в макете орбиты.

**Исправлено 28.10.2026.** Плашка `.chip.chip--sm` (24 px), оба набора строки одинаковой ширины — стык бесшовный.
