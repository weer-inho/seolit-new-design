# Макеты

Экспорт артбордов из холста дизайна. HTML-файлы открываются в браузере и анимированы так, как задумано.
Это **референс**, а не код сайта: не копируйте их разметку как есть, переводите цвета в токены и логику — в модули `js/main.js`.

| Файл | Экран | Статус |
|---|---|---|
| `hero-notion.html`, `hero-notion.png` | Первый экран, 1440 px | ✅ реализован в `#hero` |
| `hero-notion-mobile.html`, `hero-notion-mobile.png` | Первый экран, телефон 390 px | ✅ реализован |
| `ai-coauthor.html`, `ai-coauthor.png` | ИИ-соавтор, 1440 px | ✅ реализован в `#ai` |
| `site-hero-desktop.png`, `site-hero-mobile.png` | Как сейчас выглядит сайт | для сравнения |
| `3d-variants.html` (+ `.css`, `.js`) | Битрикс24: 5 вариантов 3D вместо куба, живое демо | ✅ на сайте: слои — `#bitrix`, телефон — `#auto`, веер — `#how`, сфера — `#start`; призма отклонена. Данные соцсетей в `.js` — копия из `js/main.js` |

Макет ИИ-соавтора обрезан снизу: три карточки под окном есть в HTML, но не поместились в кадр 960 px.

## Что не перенесено в макеты
Остальные экраны (автопостинг, песочница, цена, график, старт) сразу сделаны в коде — их «макет» это сам сайт. Описание — в `../SPEC.md`.
