Слои в изометрии

Снизу — Битрикс24 с задачей, посередине — SEOlit, сверху — 12 соцсетей. Пакеты поднимаются по слоям, соцсеть вспыхивает. Прямо показывает путь «из CRM в соцсети».

  • Руками: тянуть — поворот и наклон; наведение — слои расходятся.
  • Телефон: сцена меньше, жест по горизонтали крутит.
  • Reduce: сцена стоит, пакеты не летят, соцсети вспыхивают по очереди.

Шестигранная призма

На каждой грани — один и тот же пост в оформлении разных соцсетей. Показывает «своё оформление для каждой».

  • Руками: тянуть — поворот с инерцией, клик — следующая грань.
  • Телефон: призма меньше, свайп вбок крутит.
  • Reduce: не крутится сама; грани меняются проявлением раз в 3 с.

Веер карточек

Впереди задача из Битрикс24. Каждые несколько секунд из неё веером разлетаются посты по соцсетям и снова собираются.

  • Телефон: касание раскрывает.
  • Reduce: веер раскрыт и стоит; карточки подсвечиваются по очереди.

Телефон в 3D

Смартфон с лентой медленно поворачивается, пост из карточки Битрикс24 перелетает в ленту — каждый раз в новой соцсети.
