# Промпты для Claude Code

Выполняйте по порядку. Один промпт — одна сессия задач; после каждого проверьте сайт в браузере и сделайте `git push`.

| № | Файл | Что делает |
|---|---|---|
| 01 | [01-motion-and-scroll.md](01-motion-and-scroll.md) | Сайт не замирает при «уменьшении движения», пошаговая прокрутка по экранам, плашки в бегущей строке |
| 02 | [02-ai-coauthor-screen.md](02-ai-coauthor-screen.md) | Новый экран «ИИ-соавтор» по макету |
| 03 | [03-links-and-cta.md](03-links-and-cta.md) | Реальные ссылки: вход, регистрация, Битрикс24, подвал |
| 04 | [04-qa-mobile-performance.md](04-qa-mobile-performance.md) | Проверка телефона, темы, скорости, доступности |
| — | [templates.md](templates.md) | Шаблоны для своих задач: новый экран, исправление, мелкая правка |

## Как отправлять
- Копируйте всё внутри блока «Промпт».
- Скриншоты вставляйте в Claude Code через Ctrl+V прямо в сообщение.
- Для 01 и 02 включите режим плана (Shift+Tab, пока внизу не появится «plan mode»): Claude Code сначала покажет план, вы его одобрите.
- Если результат не тот — не переписывайте промпт, а ответьте: «Не так: <что видите>. Должно быть: <что ждёте>» + скриншот.

## Как проверить в браузере
PhpStorm: правый клик по `index.html` → Open In → Browser. После правки — сохранить и обновить страницу (F5).
Если кажется, что изменения не подхватились — Ctrl+F5.
