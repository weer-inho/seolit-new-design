# Шаблоны промптов

Заполните `<…>` и отправьте. Движение всегда описывайте глаголами и цифрами: «уезжает вверх за 0,5 с, каждые 2,6 с» — слово «анимация» без деталей даёт случайный результат.

## Новый экран
```
Прочитай CLAUDE.md и docs/SPEC.md.
Добавь экран <название> по макету docs/design/<файл>.html (скриншот прикладываю).
Место: новая <section class="scr" id="<id>"> после #<id>.
Тексты: <точные тексты или «из макета»>. Ничего не выдумывай сверх них.
Движение:
- <элемент> — <что делает>, <время / частота>;
- <элемент> — <что делает при наведении / клике / перетаскивании>;
- параллакс: <элемент> data-speed="<число>".
Режим reduced — по таблице в SPEC.md.
Телефон 390 px: <что упростить, скрыть, переставить>.
Добавь точку в #dots. Модуль — отдельная функция в js/main.js через watch().
Обнови SPEC.md и CLAUDE.md. Проверь консоль и 390 px. Коммит.
```

## Исправление
```
Ошибка: <что вижу> (скриншот прикладываю).
Ожидаю: <как должно быть>.
Где: экран #<id>, <ПК / телефон / тёмная тема>.
Сначала найди причину и опиши её одной-двумя фразами, потом исправь.
Не меняй другие экраны. Проверь, что исправление работает и в режиме reduced-motion. Коммит.
```

## Мелкая правка
```
На экране #<id> замени <что> на <что>. Больше ничего не трогай. Коммит.
```

## Откат неудачной правки
```
Последний коммит сломал <что>. Откати его через git revert и покажи, что вернулось.
```
