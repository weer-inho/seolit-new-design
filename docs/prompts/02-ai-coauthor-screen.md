# 02. Экран «ИИ-соавтор»

Перед отправкой: режим плана (Shift+Tab). Вставьте в сообщение скриншот `docs/design/ai-coauthor.png` (Ctrl+V) — Claude Code лучше понимает картинку плюс HTML.

## Промпт
```
Прочитай CLAUDE.md и docs/SPEC.md, экран «8. ИИ-соавтор».
Реализуй этот экран по макету docs/design/ai-coauthor.html (скриншот прикладываю).
Макет — референс: перенеси вид и движение, но код пиши в стиле проекта, а не копируй разметку.

Место: новая секция <section class="scr" id="ai"> между #schedule и #bitrix.
Экран тёмный в обеих темах. Заведи для него свои токены (например --ai-bg, --ai-surface, --ai-line, --ai-muted)
во всех трёх местах из CLAUDE.md, светлая карточка формы — через существующие светлые значения.

Контент — строго из SPEC.md: заголовок, подзаголовок, 4 модели Yandex, поля формы, окно соавтора,
«1 токен Lite: 0,0002 ₽», три карточки внизу. Других цен и функций не добавляй.

Движение (модуль aiCoauthor в js/main.js, через watch()):
- модели подсвечиваются по очереди каждые 2 с, плашки сверху и пункт в списке «Подключение ИИ» синхронно;
- цикл демо ~9 с: запрос в рамке светится → «ОТПРАВИТЬ ЗАПРОС» нажимается (scale 0.95) →
  в «Ответ» мерцает «Пишу анонс…» → ответ печатается (≈35 символов/с) → текст переносится
  в поле «Текст публикации» формы слева;
- ползунок «Случайность» плавно ходит 38% ↔ 62% (5 с);
- кнопка «ИИ соавтор» с роботом пульсирует кольцом, робот слегка подпрыгивает;
- параллакс: заголовок data-speed="-0.05", окно соавтора data-speed="0.04".
Интерактив:
- клик по модели (плашка или пункт списка) выбирает её и перезапускает цикл;
- клик «ОТПРАВИТЬ ЗАПРОС» запускает цикл сразу; повторный клик во время цикла ничего не ломает;
- ползунок можно двигать руками (настоящий <input type="range">), автодвижение после этого останавливается.
Режим reduced — по таблице «Уменьшение движения» в SPEC.md: без пульсации и печати, смены — проявлением.

Телефон (390 px): форма и окно соавтора одно под другим, плашки моделей в 2 ряда, карточки внизу в 1 колонку.

Также: точка «ИИ-соавтор» в #dots, ссылка «ИИ» в шапке (.hdr__nav) на #ai.
Проверь консоль, ширину 390 px, обе темы. Обнови SPEC.md (статус ✅), CLAUDE.md (список экранов), docs/design/README.md.
Сделай коммит.
```

## Как проверить руками
- Модели подсвечиваются по очереди, текст ответа печатается и появляется в форме слева.
- Клик по «Yandex GPT Pro» — подсветка переходит на неё, цикл начинается заново.
- Переключите тему — экран остаётся тёмным, остальные меняются.
- 390 px — всё в одну колонку, ничего не вылезает за край.
