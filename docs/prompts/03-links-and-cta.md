# 03. Реальные ссылки и регистрация

Перед отправкой впишите адреса вместо `[…]`. Если какого-то адреса нет — удалите строку, ссылка останется заглушкой.

## Промпт
```
Прочитай CLAUDE.md. Замени заглушки href="#" на реальные адреса:

- «Вход» в шапке → [АДРЕС ВХОДА, например https://seolit.ru/...]
- все кнопки «Попробовать», «Попробовать 3 дня бесплатно», «Начать работу» → [АДРЕС РЕГИСТРАЦИИ]
  (кнопка «Начать работу» сначала запускает конфетти, через 700 мс переходит по ссылке;
   при reduced-motion — переходит сразу);
- «Мы в Битрикс24» → https://www.bitrix24.ru/apps/app/advina.seolit/
- подвал: «Инструкция» → [АДРЕС], «Прайс» → [АДРЕС], «Рефералы» → [АДРЕС], «Блог» → [АДРЕС], «Контакты» → [АДРЕС].

Внешние ссылки открывай в той же вкладке, кроме Битрикс24 (target="_blank" rel="noopener").
Кнопка «Посмотреть, как работает» остаётся якорем на #nets.
Найди и перечисли оставшиеся href="#", если они есть.
Обнови раздел TODO в CLAUDE.md и «Не подключено» в docs/SPEC.md. Сделай коммит.
```
