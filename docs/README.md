## Как работать
1. Откройте папку проекта в PhpStorm и запустите Claude Code во вкладке терминала.
2. Возьмите следующий по номеру промпт из `prompts/`, скопируйте блок «Промпт» целиком и отправьте.
3. Проверьте результат в браузере: правый клик по `index.html` → Open In → Browser.
4. Если всё хорошо — Claude Code делает коммит, вы отправляете на GitHub: `git push` (или Ctrl+Shift+K в PhpStorm).
5. Если нет — пришлите в Claude Code скриншот и одну фразу о том, что не так.

## Главное правило для любых правок
Код — единственный источник правды о том, как сайт работает сейчас. `SPEC.md` описывает, как он **должен** работать.
Если код и спецификация расходятся, а задача этого не касается, — спецификацию обновляют в том же коммите.
