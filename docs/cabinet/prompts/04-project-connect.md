# 04. Проект и подключение приёмника

Скриншоты: `design/png/project-ru-dark.png`, `design/png/connect-ru-light.png`, `design/png/m-project-ru-light.png`, `design/png/m-connect-ru-light.png`.

## Промпт
```
Прочитай CLAUDE.md, docs/cabinet/SPEC.md (4.4, 4.5) и исходники docs/cabinet/design/source/Project.dc.html,
Connect.dc.html, MProject.dc.html, MConnect.dc.html. Скриншоты прикладываю.

1. app/project.html?id=… по макету и SPEC 4.4. Данные проекта shop — 14 источников и 62 приёмника группами по соцсетям
   (в data.js можно хранить группы с несколькими «показанными» аккаунтами и общим числом). Для других id — свои данные
   поменьше; неизвестный id → проект shop.
   - Вкладки (неактивная — --muted, активная — --fg с синей полосой; в макете ошибочно синие), четыре карточки с числами
     и спарклайном, «Разобрать» включает фильтр «Ошибки».
   - Источники и приёмники: поиск, чипы-фильтры, сворачиваемые группы, переключатели вкл/выкл меняют счётчики,
     строки с ошибкой с кнопкой действия (клик → toast, ошибка исчезает, счётчики обновляются), меню «⋯», удаление с подтверждением.
   - Пустое состояние источников.
   - Телефон — как m-project: числа 2×2, переключатель «Приёмники/Источники», чипы прокручиваются, плоский список.
2. Окно «Подключить приёмник» по SPEC 4.5: открывается кнопкой и по #connect; поиск и категории работают; плитка
   «Входит в тариф» / «Уже подключён: N · ещё +100 ₽/мес» по реальному числу аккаунтов этой соцсети в проекте;
   шаги 2 и 3 имитируются; после «Подключить» приёмник появляется в группе, toast.
   На телефоне — шторка снизу. Esc и крестик закрывают, фокус возвращается на кнопку.
   То же окно в режиме «Подключить источник» (список источников из SPEC 4.5).

Проверь 1440 и 390 px, обе темы, RU/EN/KZ, клавиатуру в окне. Отметь статусы в SPEC. Коммит.
```

## Как проверить
- «Разобрать» → остались только строки с ошибками; «Переподключить» → ошибка исчезла, «Ошибки» стало на 1 меньше.
- Свернуть/развернуть группу ВКонтакте; выключить аккаунт — счётчик «работают» уменьшился.
- «+ Подключить» → найти «tele» → Telegram → Продолжить → Войти → выбрать группу → Подключить → новый приёмник в группе Telegram.
- На телефоне окно выезжает снизу и не перекрывается нижними вкладками.
