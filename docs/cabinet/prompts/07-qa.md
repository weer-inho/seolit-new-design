# 07. Проверка перед показом

## Промпт
```
Прочитай CLAUDE.md и docs/cabinet/SPEC.md (раздел 6 «Готово, когда»). Проведи проверку демо-кабинета и исправь найденное.
Если есть Playwright — используй его для скриншотов и обхода ссылок; если нет — проверяй по коду и напиши, что не проверено.

1. Сквозной путь: лендинг «Попробовать» → регистрация → проекты → проект → подключить приёмник → новый пост → очередь;
   и лендинг «Вход» → вход → проекты. Ни одного тупика и ошибки в консоли.
2. Каждая страница app/*: 390×844, 360×740, 768×1024, 1440×900, 1920×1080; светлая и тёмная тема; RU, EN, KZ.
   Нет горизонтальной прокрутки, текст не обрезан (казахский и английский длиннее), касаемые элементы ≥ 44 px.
3. Нет русских строк в EN/KZ (найди все тексты вне i18n.js). Множественное число верное.
4. Все ссылки: нет href="#" без обработчика, разделы без макета → soon.html, пути относительные
   (сайт живёт по адресу https://weer-inho.github.io/seolit-new-design/).
5. Доступность: клавиатура, видимый фокус, окна и шторки (Esc, возврат фокуса), aria-label у кнопок-значков,
   контраст ≥ 4.5:1 в обеих темах, prefers-reduced-motion.
6. Тема и язык сохраняются между страницами и между лендингом и кабинетом (тема).
7. «Сбросить демо» возвращает исходные данные.

Отчёт — docs/cabinet/QA.md, скриншоты — docs/cabinet/qa/. Отметь статусы в SPEC. Коммит.
```
