# 08. Следующие разделы (шаблон)

Когда появятся макеты баланса, расписаний, шаблонов и т. д.: положите PNG в `docs/cabinet/design/png/`, исходники — в `design/source/`, допишите раздел в `SPEC.md` (4.8, 4.9…) и отправьте промпт ниже.

## Промпт
```
Прочитай CLAUDE.md, docs/cabinet/SPEC.md (раздел 4.<N>) и docs/cabinet/design/source/<Файл>.dc.html. Скриншоты прикладываю.

Сделай app/<страница>.html по макету и SPEC 4.<N>, на общей оболочке app.js, тексты через i18n.js (RU/EN/KZ),
данные — в data.js. Пункт меню «<Раздел>» теперь ведёт сюда, а не на soon.html.
Что должно работать: <перечислить кнопки, фильтры, формы>.
Что имитируется toast-ом: <оплата, сохранение на сервере и т. п.>.
Телефон: <что меняется на 390 px>.

Проверь 1440 и 390 px, обе темы, три языка, клавиатуру. Отметь статус в SPEC. Коммит.
```

## Что осталось нарисовать
Баланс (пополнение, способы оплаты с комиссиями, купон, история), Расписания (сетка 7 × 24 с закрашиванием мышью и пальцем, пресеты),
Шаблоны (список и редактор с переменными #TITLE#, #TEXT#, #URL#, #TAGS#), Водяные знаки (редактор с перетаскиванием),
Автокартинки, Рефералы, API (ключи, спецификации), RSS-тест, Помощь, Настройки профиля (часовой пояс, язык, уведомления).
