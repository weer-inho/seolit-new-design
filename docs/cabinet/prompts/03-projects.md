# 03. Проекты

Скриншоты: `design/png/projects-ru-light.png`, `design/png/m-projects-ru-dark.png`.

## Промпт
```
Прочитай CLAUDE.md, docs/cabinet/SPEC.md (4.3) и исходники docs/cabinet/design/source/Main.dc.html и MProjects.dc.html
(тексты на трёх языках, данные, токены). Скриншоты прикладываю.

Сделай app/projects.html по макету и SPEC 4.3. Карточки строй из data.js, тексты — через i18n.js.
- Блок «Требует внимания» показывается, только если есть проблемы; кнопки ведут куда сказано в SPEC.
- Карточка проекта целиком по SPEC: статус, значки соцсетей + «+N», три числа (ошибки красным, если > 0),
  срок оплаты с полоской, кнопки. «Оплатить»/«Продлить» — toast «Демо: …».
- «Новый проект» — окно с названием и сайтом; «Создать» добавляет карточку со статусом «Демо» (sessionStorage).
- «Доступны мне», строка новостей, совет.
- Поиск в верхней панели фильтрует карточки по названию и сайту; пустой результат — понятное сообщение.
- Телефон (< 900 px) — как m-projects: карточка баланса, плашка «Требует внимания», упрощённые карточки.
- Правильные формы множественного числа («1 ошибка», «2 ошибки», «5 ошибок»).

Проверь 1440 и 390 px, обе темы, RU/EN/KZ, клавиатуру. Отметь статус в SPEC. Коммит.
```

## Как проверить
- Сравнить с `projects-ru-light.png` и `projects-en-dark.png`.
- «Новый проект» → создать → карточка появилась, после обновления страницы она на месте.
- Ввести в поиск «блог» — осталась одна карточка.
