# 05. Очередь публикаций

Скриншоты: `design/png/queue-ru-light.png`, `design/png/queue-ru-dark.png`.

## Промпт
```
Прочитай CLAUDE.md, docs/cabinet/SPEC.md (4.6) и docs/cabinet/design/source/Queue.dc.html. Скриншоты прикладываю.

Сделай app/queue.html (?project=… — посты одного проекта, без параметра — все проекты) по макету и SPEC 4.6.
- Сегменты статусов и их числа берутся из data.js; «Ошибки 0» — пустое состояние.
- Поиск по тексту и фильтр приёмников работают.
- Группы по дням с датами от сегодняшнего дня на текущем языке.
- «Опубликовать сейчас» → toast «Демо: …», пост переходит в «Опубликовано»; «Изменить» → post.html?id=…;
  «⋯»: Перенести (окно с датой и временем), На паузу, Удалить (подтверждение).
- Флажки и липкая панель выбранных; действия работают сразу для всех выбранных.
- Переключатель «Список / Календарь»: календарь — 7 колонок по дням с карточками постов (можно упрощённо).
- Телефон (< 900 px): строки становятся карточками, действия — в «⋯», панель выбранных — над нижними вкладками.
- Пост, созданный на post.html, появляется здесь (sessionStorage).

Проверь 1440 и 390 px, обе темы, RU/EN/KZ. Отметь статус в SPEC. Коммит.
```

## Как проверить
- Отметить два поста → снизу панель «Выбрано: 2» → «На паузу» → посты ушли во вкладку «На паузе».
- Вкладка «Ошибки» — зелёная галочка «Ошибок нет».
- На 390 px нет горизонтальной прокрутки.
