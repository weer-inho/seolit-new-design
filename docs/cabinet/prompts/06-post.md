# 06. Новый пост

Скриншоты: `design/png/post-ru-light.png`, `design/png/post-kk-dark.png`.

## Промпт
```
Прочитай CLAUDE.md, docs/cabinet/SPEC.md (4.7) и docs/cabinet/design/source/Post.dc.html. Скриншоты прикладываю.
Для ИИ-соавтора посмотри и экран #ai на лендинге — модели и цена там уже есть.

Сделай app/post.html (и режим редактирования ?id=…) по макету и SPEC 4.7.
- Счётчики символов ВК / TG / X считаются вживую; превышение — --warn и «сократится».
- ИИ-соавтор: блок с моделью (Yandex GPT Lite / Pro, Llama 8B / 70B), инструкцией, «Случайность», токенами,
  ценой Lite 0,0002 ₽; «Переписать» → через 1,5 с текст заменяется вариантом из data.js с эффектом печати
  (при reduced-motion — сразу), «Вернуть как было». Других цен не указывать.
- Фото и видео: настоящий <input type="file">, миниатюры через URL.createObjectURL, удаление, лимит 10.
- Хэштеги — чипы; «Когда» — Сразу / Запланировать / Черновик с датой и временем; «Дополнительно» — свёрнуто,
  маркировка рекламы раскрывает поля ERID и текст.
- «Куда»: поиск, «Все работающие», группы с флажками, раскрытие до аккаунтов; число в заголовке и в кнопке отправки.
- Предпросмотр ВКонтакте / Telegram / OK обновляется при вводе.
- Проверка формы по SPEC; отправка добавляет пост в демо-очередь → queue.html + toast «Пост запланирован».
- Телефон: одна колонка, кнопка отправки прилипает к низу над вкладками.

Проверь 1440 и 390 px, обе темы, RU/EN/KZ. Отметь статус в SPEC. Коммит.
```

## Как проверить
- Набрать длинный текст — счётчик X стал оранжевым.
- ИИ-соавтор → «Переписать» → текст заменился, «Вернуть как было» вернул.
- Выбрать 2 фото с компьютера — появились миниатюры.
- «Запланировать» → открылась очередь, новый пост в списке.
