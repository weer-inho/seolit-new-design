## Как отправлять
- Копируйте блок «Промпт» целиком.
- Вставьте 1–2 скриншота из `docs/cabinet/design/png/`, указанных в промпте (Ctrl+V прямо в сообщение). Claude Code может открыть их и сам, но картинка в сообщении работает надёжнее.
- Если результат не тот: «Не так: <что видите>. Должно быть: <что ждёте>» + скриншот.

## Как смотреть
- Локально: PhpStorm → правый клик по `app/login.html` → Open In → Browser.
- Телефон без телефона: в браузере F12 → значок телефона → ширина 390.
- После `git push`: https://weer-inho.github.io/seolit-new-design/app/login.html (обновляется 1–2 минуты; если видите старое — Ctrl+F5).
