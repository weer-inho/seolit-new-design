# 01. Каркас демо-кабинета

Скриншоты в сообщение: `design/png/projects-ru-light.png` и `design/png/m-projects-ru-dark.png`.

## Промпт
```
Прочитай CLAUDE.md, docs/cabinet/README.md, docs/cabinet/SPEC.md (разделы 1–3 и 5) и docs/cabinet/design/README.md.
Посмотри исходники docs/cabinet/design/source/Sidebar.dc.html, TopBar.dc.html, Main.dc.html и MProjects.dc.html
(там токены, значки, тексты на трёх языках). Скриншоты прикладываю.

Задача: сделать каркас статичного демо-кабинета в папке app/. Без сборки и npm, как лендинг.

1. Вынеси NETS, ICONS и icon() из js/main.js в js/nets.js (глобальный объект, например window.SEOLIT_NETS).
   Лендинг подключает js/nets.js перед main.js и работает как раньше — проверь это отдельно.
   Добавь соцсети, нужные кабинету: Max.ru, Facebook, Instagram, RSS, YouTube (значки — из открытых наборов,
   лицензию в комментарии у ICONS; нет значка — подпись на плашке).
2. app/css/app.css: токены из SPEC 3.1 (светлые на :root + два тёмных блока по правилу CLAUDE.md), базовые
   компоненты: кнопки (основная, обычная, тихая, маленькая), пилюли статусов (ok/err/warn/info/off), карточка,
   поле ввода, чипы-фильтры, сегменты, переключатель, флажок, плашка соцсети 22/28/40 px, окно, шторка, toast.
3. app/js/i18n.js: словари ru/en/kk (тексты оболочки взять из Sidebar/TopBar.dc.html), t(), plural() через
   Intl.PluralRules, формат дат и денег, язык из ?lang= → localStorage['seolit-lang'] → ru. Применение к
   [data-i18n] и [data-i18n-attr], событие смены языка без перезагрузки.
4. app/js/data.js: демо-данные из SPEC 3.4 (даты от сегодняшнего дня), хранение действий в sessionStorage, сброс.
5. app/js/app.js: оболочка по SPEC 3.5 — меню слева (липкое, на всю высоту), верхняя панель (крошки, поиск,
   RU·EN·KZ, тема с общим ключом seolit-theme, колокольчик с выпадашкой, «Новый пост», меню аватара),
   на < 900 px — нижние вкладки и шторка «Ещё», баннер демо, toast. Страница задаёт себя через
   <div id="shell" data-page="..."> и data-crumbs.
6. app/soon.html — заглушка разделов без макета (?s=balance|schedules|templates|watermarks|autoimg|referrals|api|rss|help|settings);
   все такие пункты меню ведут на неё. app/index.html — переход на login.html или projects.html (если был демо-вход).
7. Временная app/projects.html с оболочкой и заголовком «Проекты» (сам экран — в промпте 03), чтобы проверить каркас.

Проверь: 1440 и 390 px, обе темы, три языка, клавиатура (Tab, Esc закрывает выпадашки и шторку), консоль без ошибок,
лендинг не сломан. Обнови CLAUDE.md: раздел «Демо-кабинет» — структура app/, правила (тексты только через i18n,
данные только из data.js, оболочка из app.js). Отметь статусы в docs/cabinet/SPEC.md. Коммит.
```

## Как проверить
- Открыть `app/projects.html`: слева меню, сверху панель, переключение RU/EN/KZ меняет все надписи, луна/солнце — тема.
- Сузить окно до 390: меню исчезло, снизу вкладки, «Ещё» открывает шторку с остальными разделами.
- Любой пункт без макета (Баланс, Шаблоны…) открывает заглушку «появится позже».
- Лендинг `index.html` выглядит и работает как раньше, значки соцсетей на месте.
