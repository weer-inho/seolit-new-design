# 00. Автопилот: все шаги подряд с сохранением прогресса

Один промпт вместо 01–07. Claude Code идёт по шагам и коммитит после каждого. Если токены закончатся посреди работы, сделанное уже лежит в коммитах. Через пару часов отправьте этот же промпт ещё раз: работа продолжится с места остановки по файлу `docs/cabinet/PROGRESS.md`.

Режим плана не нужен. Удобнее включить auto mode (Shift+Tab), чтобы Claude Code не спрашивал разрешения на каждый файл.

## Промпт
```
Работай в режиме автопилота по демо-кабинету. Прочитай CLAUDE.md, docs/cabinet/README.md, docs/cabinet/SPEC.md,
docs/cabinet/design/README.md и docs/cabinet/prompts/README.md.

Прогресс веди в docs/cabinet/PROGRESS.md. Если файла нет — создай его со списком шагов 01–07 из docs/cabinet/prompts/
(все «не начат»). Если есть — продолжай с первого незавершённого шага; шаг «в работе» сначала проверь
(git status, git log, что уже есть в app/) и доделай, а не начинай заново.

Для каждого шага по порядку:
1. Отметь шаг в PROGRESS.md как «в работе», закоммить.
2. Выполни задание из блока «Промпт» в docs/cabinet/prompts/<NN>-*.md. Скриншоты, которые там названы, открой сам
   из docs/cabinet/design/png/. Вопросов не задавай: где не хватает деталей — решай по SPEC.md и макетам,
   решение запиши одной строкой в PROGRESS.md.
3. Коммить маленькими порциями: после каждой законченной части шага (например, «стили», «i18n», «оболочка»),
   чтобы при внезапной остановке сделанное не пропало. Перед каждым коммитом сайт должен открываться без ошибок
   в консоли — не коммить сломанное. Сообщение коммита: «Кабинет <NN>: <что сделано>».
4. Проверь по «Как проверить» из промпта (если есть Playwright — скриншоты 1440 и 390 px в docs/cabinet/qa/).
5. Отметь шаг «готов» в PROGRESS.md и статусы в SPEC.md, закоммить. Переходи к следующему шагу без паузы.

Правила:
- git push не делай — пушу я сам.
- Не трогай то, что не относится к текущему шагу. Лендинг должен работать после каждого коммита.
- Если шаг упёрся в проблему, которую не решить, — запиши её в PROGRESS.md («блокер: …»), закоммить и иди дальше.
- Экономь токены: не перечитывай большие файлы целиком без нужды, читай нужные куски; не выводи длинные листинги.
- В конце (или когда шаги кончились) — коротко в чат: какие шаги готовы, что осталось, какие решения принял.
```

## Если работа прервалась
1. `git push` — сделанное уйдёт на GitHub Pages.
2. Когда лимит восстановится — откройте Claude Code и отправьте этот же промпт ещё раз.
