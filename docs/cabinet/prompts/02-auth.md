# 02. Вход, регистрация и переход с лендинга

Макета нет — экран описан в SPEC 4.1–4.2. Для стиля можно приложить `design/png/projects-ru-light.png` и скриншот первого экрана лендинга (доска контент-плана).

## Промпт
```
Прочитай CLAUDE.md и docs/cabinet/SPEC.md (разделы 3, 4.1, 4.2, 5).
Сделай app/login.html и app/register.html по описанию. Макета нет — держи стиль кабинета (app.css) и лендинга.

- Две колонки на ПК, одна на телефоне; сверху «← На главную», RU·EN·KZ, тема.
- Правая панель: три маленькие карточки постов со значками соцсетей, статус меняется «12:00 → публикуется… → ✓ в N соцсетях»
  каждые ~2 с (при prefers-reduced-motion — проявлением, без движения) и три факта: 12 соцсетей, 800 ₽ в месяц за проект, 3 дня бесплатно.
- Демо-вход: любой email и непустой пароль → localStorage['seolit-demo-user'] → projects.html. Ошибки под полями,
  aria-invalid, фокус на первое поле с ошибкой. «Войти в демо без пароля» → anna@example.ru.
  «Забыли пароль?» → подсказка «В демо пароль не нужен».
- Регистрация: email, пароль (показать/скрыть), флажок оферты (ссылка — см. TODO в SPEC 4.2), кнопка
  «Создать аккаунт и получить 3 дня бесплатно» → экран «Аккаунт создан» → «Создать первый проект».
- «Выйти» в меню аватара ведёт на login.html и забывает демо-пользователя.
- Тексты на трёх языках через i18n.js.

Лендинг (SPEC 5): «Вход» → app/login.html, «Попробовать», «Попробовать 3 дня бесплатно», «Начать работу» → app/register.html.
Конфетти у «Начать работу» сохрани. Обнови раздел «Ссылки» в docs/SPEC.md и CLAUDE.md.

Проверь путь лендинг → регистрация → проекты и лендинг → вход → проекты на 1440 и 390 px, в обеих темах. Коммит.
```

## Как проверить
- На лендинге «Попробовать» открывает регистрацию, «Вход» — вход.
- Пустая форма — понятные ошибки; заполненная — попадаете в «Проекты».
- Аватар → «Выйти» → снова вход.
