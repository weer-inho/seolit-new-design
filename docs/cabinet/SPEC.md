# ТЗ: демо кабинета SEOlit

Статусы: 🆕 нужно сделать · ✅ сделано · 🔧 нужна правка. Отмечайте статус в этом файле в том же коммите, что и работу.

## 1. Цель и границы
- Кликабельная статичная копия нового интерфейса кабинета для демонстрации: можно войти, походить по разделам, понажимать кнопки, переключить язык и тему, открыть с телефона.
- **Без сервера и базы.** Только HTML + CSS + JS, без сборки и npm (как лендинг). Работает с `file://` и на GitHub Pages.
- Данные вымышленные (`app/js/data.js`). Никаких настоящих email, проектов, ключей API — страницы публичные.
- То, что требует сервера (оплата, публикация, вход через соцсеть), имитируется: кнопка срабатывает, показывает уведомление «Демо: …» или переводит на следующий экран.
- Источник правды по виду — макеты в `design/`. Источник правды по текстам и переводам — словари `T` в `design/source/*.dc.html`.

## 2. Структура файлов
```
app/
  index.html        → сразу ведёт на login.html (или projects.html, если демо-вход уже был)
  login.html        вход
  register.html     регистрация
  projects.html     список проектов
  project.html      проект: ?id=shop|news|travel|cook|signal; окно «Подключить приёмник» — по кнопке и по адресу #connect
  queue.html        очередь публикаций (?project=shop, по умолчанию все проекты)
  post.html         новый пост / редактирование (?id=<пост>)
  soon.html         заглушка для ещё не нарисованных разделов: ?s=balance|schedules|templates|…
  css/app.css       стили кабинета
  js/i18n.js        словари ru / en / kk, t(), plural(), форматы дат и чисел
  js/data.js        демо-данные
  js/app.js         оболочка (меню, верхняя панель, нижние вкладки на телефоне, тема, язык, уведомления) и модули страниц
js/nets.js          общий для лендинга и кабинета: NETS, ICONS, icon() — вынести из js/main.js
```
- Все пути относительные (`../js/nets.js`, `css/app.css`) — сайт живёт по адресу `/seolit-new-design/`, не в корне домена.
- На каждой странице: `<html lang>` по текущему языку, свой `<title>` («Проекты — SEOlit»), `<meta name="viewport">`, favicon `../favicon.svg`, шрифты как на лендинге.
- Общие куски (меню, верхняя панель, нижние вкладки, баннер демо) не копируются в каждый HTML, а строятся из `app.js`: в разметке страницы только `<div id="shell" data-page="projects">` и содержимое `<main>`.

## 3. Общие правила

### 3.1 Стиль ✅
- Тот же язык, что у лендинга: акцент `#2563EB`, Manrope (весь кабинет — только Manrope, без Unbounded), логотип A (`#logo`, `#mark`), белые значки соцсетей на цветных плашках из `js/nets.js`.
- Токены — как на лендинге, плюс свои для кабинета. Имена и значения — блок `.app` / `.app.dark` в `design/source/Main.dc.html`: `--bg --surface --fg --muted --faint --line --soft --accent --atext --ok --ok-bg --err --err-bg --warn --warn-bg --shadow --overlay`. В `app.css` задать их на `:root` и в двух тёмных блоках по правилу CLAUDE.md.
- Радиусы: карточки 16 px, кнопки 11 px, мелкие кнопки 9 px, плашки соцсетей 8–12 px, «пилюли» — полностью скруглённые.
- Значки интерфейса — линейные SVG 24×24, обводка 2 px (набор и пути — в `design/source/Sidebar.dc.html` и других файлах). Эмодзи не использовать.
- Цифры в колонках — `font-variant-numeric: tabular-nums`.
- Контраст текста ≥ 4.5:1 в обеих темах. Цвет — не единственный признак состояния: у ошибки есть и цвет, и текст, и значок.

### 3.2 Тема ✅
- Ключ `localStorage['seolit-theme']` — общий с лендингом: выбор на лендинге переносится в кабинет и обратно. По умолчанию — системная.
- Кнопка солнце/луна в верхней панели (на телефоне — в шапке). Переключение без перезагрузки.

### 3.3 Языки ✅
- RU (основной), EN, KZ. Переключатель «RU · EN · KZ» в верхней панели, на страницах входа/регистрации и в меню «Ещё» на телефоне.
- Выбор запоминается в `localStorage['seolit-lang']`; адрес `?lang=en` имеет приоритет (чтобы давать ссылку сразу на английскую версию).
- Все строки — в `app/js/i18n.js`: `{ ru: {...}, en: {...}, kk: {...} }`. В HTML — атрибуты `data-i18n="key"` (текст), `data-i18n-attr="placeholder:key;aria-label:key2"`; динамические списки строятся из JS через `t(key)`.
- Переводы брать из словарей `T` в `design/source/*.dc.html`; чего там нет — переводить в том же стиле. **Казахский — черновой**, в начале `i18n.js` комментарий «KZ: нужна вычитка носителем».
- Множественное число — через `Intl.PluralRules` (в макетах есть ошибка «1 ошибки» — так нельзя): `plural(n, { one, few, many, other })`.
- Даты и числа — `Intl.DateTimeFormat` / `Intl.NumberFormat` с локалью `ru-RU` / `en-US` / `kk-KZ`. Валюта всегда ₽ (сервис российский).
- Лендинг остаётся только на русском.

### 3.4 Демо-данные и «время» ✅
- `data.js` описывает: пользователь (`anna@example.ru`, баланс 4 300 ₽), 4 своих проекта + 1 чужой (см. экран «Проекты»), источники и приёмники проекта `shop` (14 и 62 — группами по соцсетям, как в макете), очередь (≥ 12 постов на 3 дня), новости.
- Названия проектов и постов — на трёх языках (в макетах они переводятся, это часть демо).
- Даты считаются **от текущего дня**, чтобы демо не устаревало: «сегодня 15:30», «оплачен до» = сегодня + 20 дней и т. д.
- Действия пользователя (созданный пост, выключенный приёмник, удалённый пост) хранятся в `sessionStorage['seolit-demo']` и видны на других страницах до закрытия вкладки. В меню аватара — «Сбросить демо».

### 3.5 Оболочка ✅
- **ПК (≥ 900 px):** слева меню 248 px на всю высоту, липкое (как в макете, но до низа окна). Группы: Работа (Проекты, Очередь со счётчиком, Шаблоны, Расписания), Оформление (Водяные знаки, Автокартинки), Аккаунт (Баланс, Рефералы, API, RSS-тест). Внизу карточка баланса «4 300 ₽ · хватит примерно на 5 месяцев · Пополнить» и «Помощь и инструкции».
- **Верхняя панель:** хлебные крошки, поиск по проектам и аккаунтам (Ctrl/Cmd+K — фокус; в демо фильтрует проекты и приёмники на текущей странице), RU · EN · KZ, тема, колокольчик (выпадашка с 2–3 уведомлениями), кнопка «Новый пост» → `post.html`, аватар (меню: email, «Сбросить демо», «Выйти» → `login.html`).
- **Телефон (< 900 px):** меню скрыто; снизу панель вкладок 64 px: Проекты · Очередь · [+] (новый пост, крупная кнопка по центру) · Баланс · Ещё. «Ещё» открывает шторку со всеми остальными разделами, языком и темой. Шапка: «назад» (на внутренних страницах), заголовок, язык, тема. Отступы под системные полосы — `env(safe-area-inset-*)`.
- **Баннер демо** над всем (одной строкой, закрывается крестиком, запоминается в `sessionStorage`): «Демо нового интерфейса. Данные вымышленные, ничего не сохраняется. Настоящий кабинет — seolit.ru» (ссылка https://seolit.ru/auth.html).
- **Уведомления (toast):** снизу по центру, 3 с, `role="status"`. Используются для действий, которые требуют сервера: «Демо: в настоящем SEOlit пост ушёл бы сейчас».
- **Пункты меню без макета** ведут на `soon.html?s=<раздел>`: та же оболочка, заголовок раздела и текст «Этот раздел появится в демо позже» + кнопка «К проектам».

### 3.6 Поведение и доступность
- Все кликабельные элементы — `<a href>` или `<button>`, поля — `<input>`/`<textarea>` с `<label>`. Фокус с клавиатуры виден. Окна — `role="dialog"`, `aria-modal`, Esc закрывает, фокус возвращается на кнопку.
- Касаемые элементы ≥ 44 px на телефоне.
- Плавные мелкие анимации 150–250 мс (наведение, раскрытие групп, появление уведомлений). При `prefers-reduced-motion` — только проявление.
- Состояния загрузки не нужны (данные локальные), но пустые состояния нужны везде, где список может быть пустым.
- Нигде нет горизонтальной прокрутки страницы. Таблицы на телефоне превращаются в карточки.

- Поля: Заголовок; Текст поста (textarea) с панелью: жёлтая кнопка «ИИ-соавтор» (как в кабинете seolit.ru), «Шаблон: Анонс ▾», счётчики символов по соцсетям (ВК / TG / X, при превышении — `--warn` и «сократится»), считаются вживую.
- «ИИ-соавтор» раскрывает блок: модель (Yandex GPT Lite / Pro, Llama 8B / 70B), готовая инструкция, текст запроса, «Случайность», «Токенов в запросе: ≈ N», «1 токен Lite — 0,0002 ₽», кнопка «Переписать» → через 1,5 с текст поста заменяется готовым вариантом из `data.js` (печатается), кнопка «Вернуть как было». Других цен моделей не указывать.
- Фото и видео: 2 загруженные миниатюры (крестик удаляет), зона «Перетащите фото или видео, или вставьте ссылку» (настоящий `<input type="file" accept="image/*,video/*" multiple>`: выбранные файлы показываются миниатюрами через `URL.createObjectURL`, никуда не отправляются), «2 / 10».
- Ссылка на материал; Хэштеги — чипы, Enter добавляет, крестик удаляет.
- Когда: «Сразу / Запланировать / Черновик» + дата и время (`<input type="date">`, `<input type="time">`) + подсказка про расписание приёмника.
- «Дополнительно» (свёрнуто): Удалить после публикации, Пометить как рекламу (раскрывает поля ERID и текст маркировки), Повторять публикацию, Геокоординаты, Автор.
- «Куда · 16 из 62»: поиск, «Все работающие приёмники», группы с флажками и «3 из 9»; группа раскрывается до отдельных аккаунтов.
- Предпросмотр: вкладки ВКонтакте / Telegram / OK, обновляется при вводе текста, заголовка, хэштегов.
- Низ: «Отмена» (→ очередь), «Сохранить черновик», основная кнопка «Запланировать на 30.10 10:00 · 16 соцсетей» / «Опубликовать в 16 соцсетей» / «Сохранить черновик». Отправка → пост добавляется в демо-очередь → `queue.html` + toast «Пост запланирован».
- Проверка формы: пустой текст и нет медиа — ошибка; ни одного приёмника — ошибка.
- `post.html?id=…` — то же, поля заполнены из поста, заголовок «Редактирование поста».
