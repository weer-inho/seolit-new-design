# Макеты кабинета

Экспорт с холста дизайна «Сеолит — кабинет» (29.10.2026). Это референс: переносить вид, тексты и поведение, но код писать в стиле проекта (токены, `app.css`, `app.js`), а не копировать разметку.

## png/ — скриншоты
Имя файла: `<экран>-<язык>-<тема>.png`. ПК — ширина 1440 px, вся высота страницы; телефон — 390 × 844.

| Экран | ПК | Телефон |
|---|---|---|
| Проекты | `projects-ru-light`, `projects-ru-dark`, `projects-en-dark` | `m-projects-ru-light`, `m-projects-ru-dark`, `m-projects-kk-light` |
| Проект | `project-ru-light`, `project-ru-dark`, `project-kk-light` | `m-project-ru-light`, `m-project-ru-dark` |
| Подключить приёмник | `connect-ru-light`, `connect-ru-dark`, `connect-en-dark` | `m-connect-ru-light`, `m-connect-ru-dark`, `m-connect-en-dark` |
| Очередь | `queue-ru-light`, `queue-ru-dark` | — (описание в SPEC.md, 4.6) |
| Новый пост | `post-ru-light`, `post-ru-dark`, `post-kk-dark` | — (описание в SPEC.md, 4.7) |

Скриншоты удобно вставлять в Claude Code (Ctrl+V) вместе с промптом.

## html/ — статичные снимки (RU, светлая)
Готовая разметка экрана без интерактива: размеры, отступы, цвета, иерархию можно смотреть в браузере и через DevTools. Шрифты грузятся с Google Fonts.

## source/ — исходники с холста (`*.dc.html`)
Формат холста: шаблон с подстановками `{{…}}`, циклы `<sc-for>`, условия `<sc-if>`, вложенные компоненты `<dc-import>` и класс `Component` с `renderVals()`. В браузере напрямую не открываются. Полезны тем, что внутри:
- словари `T = { ru, en, kk }` — **все тексты интерфейса на трёх языках** (казахский черновой);
- демо-данные: проекты, приёмники, ошибки, посты;
- токены цвета `.app` / `.app.dark` в `<style>`;
- логика: фильтры, раскрытие групп, выбор плиток, счётчики.

`Sidebar.dc.html` и `TopBar.dc.html` — общие меню и верхняя панель; `M*.dc.html` — телефонные версии.

## Известные огрехи макета (в коде исправить)
- Вкладки проекта в тёмной теме синие — должны быть `--muted`, активная `--fg`.
- «1 ошибки», «2 работают» — нужны правильные формы множественного числа.
- Меню слева заканчивается на высоте 1000 px — в коде оно на всю высоту окна и липкое.
- Строки очереди на ширине < 900 px не перестраиваются — в коде становятся карточками.
