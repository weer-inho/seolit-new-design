# Проверка демо-кабинета

29.10.2026, шаг [prompts/07](prompts/07-qa.md). Chrome 1xx через Playwright (headless), сайт открыт из подпапки `/seolit-new-design/`, как на GitHub Pages. Скриншоты — в [qa/](qa/).

## Как проверяли
- **Обход всех страниц**: `login`, `register`, `projects`, `project` (`shop`, `seolit_ru test`, `test 2`), `queue` (все проекты и магазин), `post` (новый и `?id=`), `soon` — на 390×844, 360×740, 768×1024, 1440×900, 1920×1080, в светлой и тёмной теме, на RU / EN / KZ. Всего 330 прогонов. Для каждого: ошибки и предупреждения консоли, ответы 4xx, горизонтальная прокрутка, обрезанный текст в кнопках, чипах и вкладках, кириллица в EN (кроме названий проектов и аккаунтов из данных), касаемые элементы меньше 44 px на телефоне.
- **Сквозные сценарии** (отдельный скрипт, все ✅):

## Что нашли и исправили
| Проблема | Где | Исправление |
|---|---|---|
| Касаемые элементы 32–40 px на телефоне: чипы, переключатели, «⋯», «глаз» пароля, крестики хэштегов и файлов, логотип на входе | все страницы | На < 900 px всё касаемое не меньше 44 px; у переключателя прозрачная рамка 6 px увеличивает область нажатия, видимый размер прежний |
| Цвета кнопки «ИИ-соавтор» и «Удалить» в панели выбранных были заданы напрямую | `app.css` | Токены `--ai-btn`, `--ai-btn-fg`, `--ai-btn-ring`, `--bulk-err` во всех трёх блоках тем |
| Список приёмников на телефоне показывал одну строку (`.m-only` делал `ul` флексом в ряд) | проект | `.accs.m-only` — блок |
| Строка чипов в шторке «Подключить» сжималась до нуля | окно подключения | Дети `.conn__body` не сжимаются |
| Пустая очередь: «сегодня» — объект Date, при сложении получалась строка | очередь | Числовая отметка времени |
| `$$` в строке замены превращался в `$` — ломались смена языка и фокус после подключения | `app.js` | Исправлено; замены в скриптах — функцией |
| «1 ошибки», «2 работают» из макета | проекты, проект | `Intl.PluralRules`: «1 ошибка», «2 ошибки», «5 ошибок»; «1 работает» |
| Вкладки проекта синие в тёмной теме (огрех макета) | проект | Неактивная — `--muted`, активная — `--fg` с синей полосой |
| Меню слева кончалось на 1000 px (огрех макета) | все | Липкое, на всю высоту окна |
| Строки очереди на < 900 px не перестраивались (огрех макета) | очередь | Карточки: миниатюра, текст, маршрут и время, действия в «⋯» |

## Что не проверено
- Настоящие телефоны и Safari: только Chrome в режиме телефона (касания, 390×844). Firefox и WebKit для кабинета не запускали.
- Казахские тексты черновые — нужна вычитка носителем (комментарий в начале `i18n.js`).
- Экранный диктор (NVDA, VoiceOver) не запускали: проверены только роли, подписи и порядок фокуса.
- Выбранные в «Новом посте» файлы после отправки не сохраняются (ссылки `createObjectURL` живут только на странице) — так задумано для демо.

## Этап 2: остальные разделы (29.10.2026)
Проверены новые страницы: `balance`, `templates`, `schedules`, `watermarks`, `autoimg`, `referrals`, `api`, `rss`, `help`, `settings`, `news` и вкладки проекта `?tab=stats|access|settings`. Тот же обход, что выше: 25 страниц × 5 размеров × 2 темы × 3 языка = 750 прогонов. Ошибок консоли, горизонтальной прокрутки, кириллицы в EN и обрезанных кнопок нет. Сквозные сценарии из первого этапа после изменений тоже прошли.

| Что нашли | Исправление |
|---|---|
| На телефоне ссылки на проекты в «Ближайших списаниях», ссылка на документацию API и ползунки в редакторах были ниже 44 px | На < 900 px высота не меньше 44 px |
| Вкладки проекта при открытии по прямой ссылке (`?tab=stats`) были пустыми: `sections.js` загружается после `app.js` | Событие `sections-ready` — страница проекта дорисовывает вкладку |
| Смена языка в редакторах водяных знаков и автокартинок вешала обработчики повторно | `#main` заменяется чистой копией, раздел ищет его заново |

**Исключение из правила 44 px:** клетки сетки расписания на телефоне около 13 px (24 часа в ширину 390 px). Есть пресеты, а с клавиатуры клетка переключается Enter или пробелом. Красить пальцем удобно и при таком размере: рисование идёт протяжкой.

Не проверено: экранный диктор на редакторах с перетаскиванием (у знака есть подпись с координатами и управление стрелками); скачивание PNG и CSV проверено только на то, что файл формируется, без ручного открытия.
