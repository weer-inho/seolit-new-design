|---|---|---|

## Решения
- 01: соцсети лендинга (`NETS`) не расширял — на их порядке строятся бегущая строка, песочница и сфера; новые для кабинета — отдельный `MORE`, общий список `ALL`.
- 01: знака Max.ru заливкой в открытых наборах нет (в Iconify только контурный Arcticons, CC BY-SA) — на плашке подпись «MX», как в макете.
- 01: `--faint` в светлой теме темнее макета (#636E83 вместо #6F7A8F) — у макетного 4.3:1 на фоне, мало для текста.
- 01: в Chrome нет данных ICU для kk-KZ («4,300», «M10 29») — для KZ числа и время как в ru-RU, месяцы и дни недели свои.
- 01: плашка демо на телефоне — короткий текст в одну строку («Демо: данные вымышленные. Настоящий — seolit.ru»).
- 01: тема и язык ставятся в `i18n.js`, подключённом в `<head>` без defer, — без мигания темы; остальные скрипты с defer.
- 01: счётчик «Очередь» в меню — сумма постов в очереди всех проектов (28 + 14 + 36 = 78, как в макете).
- 01: `app/index.html` закоммичен вместе со входом (шаг 02), чтобы не вести на несуществующий `login.html`.
- 02: «Создать первый проект» после регистрации ведёт на `projects.html?new=1` — там сразу откроется окно «Новый проект» (шаг 03).
- 02: email проверяется по простому шаблону `имя@домен.зона`; ошибка — под полем, `aria-invalid`, фокус на первое поле с ошибкой.
- 02: на мини-доске статус меняется по одной карточке каждые 2 с; при reduce — только проявление, спиннер стоит.
- 03: числа на карточках (в очереди / на паузе / ошибок) считаются по постам из `data.js`; посты дописаны генератором до чисел макета (28/3/0, 14/0/2, 0/12/0, 36/76/6), в меню «Очередь» — 78.
- 03: «ошибок» на карточке — посты, которые не ушли (как вкладка «Ошибки» в очереди); у магазина 0, как в макете. Ошибки подключений (6 у магазина) — на странице проекта.
- 03: у магазина 14 соцсетей (как «6 групп + ещё 8» на странице проекта), поэтому «+8», а не «+6» из макета.
- 03: «Требует внимания» собирается из данных: проект с ошибками публикации (кнопка → `project.html?id=…&filter=err`) и демо, которое кончается сегодня/завтра.
- 03: подпись под числом ошибок склоняется («1 ошибка», «2 ошибки», «5 ошибок»), пилюля — «2 ошибки».
- 03: на телефоне «Требует внимания» — свёрнутая плашка, по нажатию раскрывается список с кнопками.
- 04 (в работе): в data.js у проектов добавлены week / weekPrev / team (спарклайн, «+18 к прошлой неделе», «Доступ 3»). Дальше: тексты proj.* и conn.* в i18n.js, модуль PAGES.project и окно подключения в app.js, app/project.html, стили. Решения: неизвестный id → shop; ошибки KPI = приёмники + источники с ошибкой; на телефоне плоский список (ошибки сверху) и переключатель «Приёмники / Источники»; окно на < 900 px — шторка (APP.dialog({ sheet: true })).
- 04: на обзоре — 6 источников и 6 групп приёмников (первые две раскрыты), остальное — «Показать ещё» / «Ещё N соцсетей»; вкладки «Источники» и «Приёмники» показывают колонку целиком.
- 04: исправление ошибки (кнопка в строке) — toast «Демо: …», строка становится рабочей, счётчики пересчитываются.
- 04: «Уже подключён: N» в окне — реальное число аккаунтов этой соцсети в проекте; для источников все плитки «Входит в тариф».
- 04: RSS в окне источников — шаг «Адрес ленты» с «Проверить» (toast) вместо входа в аккаунт.
- 04: окно открывается и по #connect-source (источник), кроме #connect из ТЗ.
- После 04 (просьба владельца): выбор языка — одна кнопка с текущим языком, остальные — в выпадающем меню (вместо трёх кнопок RU · EN · KZ).
- После 04 (просьба владельца): реальные проекты со скриншотов docs/real_projects вперемешку с вымышленными. «seolit_ru test» (34 источника, 43 приёмника, 28 в очереди, 2 558 на паузе, ошибки 6 + 2), «Телеграм Сеолит» (2 RSS → «Мой Telegram»), «фб источник» — в «Моих проектах»; «Блог о путешествиях» заменён на «test 2», «Агентство «Сигнал»» — на «test123» (те же 36 / 76). Магазин, «Новости района», «Кулинарный канал» — вымышленные.
- После 04: «ошибок» на карточках проектов — ошибки подключений (приёмники + источники), как «Серьёзные ошибки» в кабинете seolit.ru; «Требует внимания» — по ним же. Ошибки публикации постов — во вкладке «Ошибки» очереди (шаг 05).
- После 04: «на паузе» у seolit_ru test (2 558) — запасом в данных (`pausedExtra`), а не тысячами постов; в меню «Очередь» теперь 106. Плашка демо: «данные демонстрационные» вместо «вымышленные».
