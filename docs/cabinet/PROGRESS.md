## Решения
- 01: соцсети лендинга (`NETS`) не расширял — на их порядке строятся бегущая строка, песочница и сфера; новые для кабинета — отдельный `MORE`, общий список `ALL`.
- 01: знака Max.ru заливкой в открытых наборах нет (в Iconify только контурный Arcticons, CC BY-SA) — на плашке подпись «MX», как в макете.
- 01: `--faint` в светлой теме темнее макета (#636E83 вместо #6F7A8F) — у макетного 4.3:1 на фоне, мало для текста.
- 01: в Chrome нет данных ICU для kk-KZ («4,300», «M10 29») — для KZ числа и время как в ru-RU, месяцы и дни недели свои.
- 01: плашка демо на телефоне — короткий текст в одну строку («Демо: данные вымышленные. Настоящий — seolit.ru»).
- 01: тема и язык ставятся в `i18n.js`, подключённом в `<head>` без defer, — без мигания темы; остальные скрипты с defer.
- 01: счётчик «Очередь» в меню — сумма постов в очереди всех проектов (28 + 14 + 36 = 78, как в макете).
- 01: `app/index.html` закоммичен вместе со входом (шаг 02), чтобы не вести на несуществующий `login.html`.
- 02: «Создать первый проект» после регистрации ведёт на `projects.html?new=1` — там сразу откроется окно «Новый проект» (шаг 03).
- 02: email проверяется по простому шаблону `имя@домен.зона`; ошибка — под полем, `aria-invalid`, фокус на первое поле с ошибкой.
- 02: на мини-доске статус меняется по одной карточке каждые 2 с; при reduce — только проявление, спиннер стоит.
- 03: числа на карточках (в очереди / на паузе / ошибок) считаются по постам из `data.js`; посты дописаны генератором до чисел макета (28/3/0, 14/0/2, 0/12/0, 36/76/6), в меню «Очередь» — 78.
- 03: «ошибок» на карточке — посты, которые не ушли (как вкладка «Ошибки» в очереди); у магазина 0, как в макете. Ошибки подключений (6 у магазина) — на странице проекта.
- 03: у магазина 14 соцсетей (как «6 групп + ещё 8» на странице проекта), поэтому «+8», а не «+6» из макета.
- 03: «Требует внимания» собирается из данных: проект с ошибками публикации (кнопка → `project.html?id=…&filter=err`) и демо, которое кончается сегодня/завтра.
- 03: подпись под числом ошибок склоняется («1 ошибка», «2 ошибки», «5 ошибок»), пилюля — «2 ошибки».
- 03: на телефоне «Требует внимания» — свёрнутая плашка, по нажатию раскрывается список с кнопками.
- 04 (в работе): в data.js у проектов добавлены week / weekPrev / team (спарклайн, «+18 к прошлой неделе», «Доступ 3»). Дальше: тексты proj.* и conn.* в i18n.js, модуль PAGES.project и окно подключения в app.js, app/project.html, стили. Решения: неизвестный id → shop; ошибки KPI = приёмники + источники с ошибкой; на телефоне плоский список (ошибки сверху) и переключатель «Приёмники / Источники»; окно на < 900 px — шторка (APP.dialog({ sheet: true })).
- 04: на обзоре — 6 источников и 6 групп приёмников (первые две раскрыты), остальное — «Показать ещё» / «Ещё N соцсетей»; вкладки «Источники» и «Приёмники» показывают колонку целиком.
- 04: исправление ошибки (кнопка в строке) — toast «Демо: …», строка становится рабочей, счётчики пересчитываются.
- 04: «Уже подключён: N» в окне — реальное число аккаунтов этой соцсети в проекте; для источников все плитки «Входит в тариф».
- 04: RSS в окне источников — шаг «Адрес ленты» с «Проверить» (toast) вместо входа в аккаунт.
- 04: окно открывается и по #connect-source (источник), кроме #connect из ТЗ.
- После 04 (просьба владельца): выбор языка — одна кнопка с текущим языком, остальные — в выпадающем меню (вместо трёх кнопок RU · EN · KZ).
- После 04 (просьба владельца): реальные проекты со скриншотов docs/real_projects вперемешку с вымышленными. «seolit_ru test» (34 источника, 43 приёмника, 28 в очереди, 2 558 на паузе, ошибки 6 + 2), «Телеграм Сеолит» (2 RSS → «Мой Telegram»), «фб источник» — в «Моих проектах»; «Блог о путешествиях» заменён на «test 2», «Агентство «Сигнал»» — на «test123» (те же 36 / 76). Магазин, «Новости района», «Кулинарный канал» — вымышленные.
- После 04: «ошибок» на карточках проектов — ошибки подключений (приёмники + источники), как «Серьёзные ошибки» в кабинете seolit.ru; «Требует внимания» — по ним же. Ошибки публикации постов — во вкладке «Ошибки» очереди (шаг 05).
- После 04: «на паузе» у seolit_ru test (2 558) — запасом в данных (`pausedExtra`), а не тысячами постов; в меню «Очередь» теперь 106. Плашка демо: «данные демонстрационные» вместо «вымышленные».
- 05: без ?project — все проекты, у строки ссылка на проект; фильтры — обычные <select> (проект, приёмник, источник, период), работают все.
- 05: «Ближайшие 7 дней» по умолчанию; для «Опубликовано» — «Последние 7 дней»; у «Ошибок» период не действует. Перенос ставит «Все даты», чтобы перенесённый пост не пропал из списка.
- 05: «Ошибки» в очереди — посты, которые не ушли (у «Новостей района» и test123), у магазина — «Ошибок нет».
- 05: на телефоне «Опубликовать сейчас» и «Изменить» — в меню «⋯», панель выбранных — над нижними вкладками.
- 06: новый пост заполнен примером из макета (заголовок, текст, 2 картинки, ссылка, хэштеги), пока его не трогали — он переключается вместе с языком; сверху выбор проекта (?project= или магазин).
- 06: ИИ-соавтор — модель, готовая инструкция (3 варианта) с редактируемым запросом, «Случайность», токены ≈ (запрос + текст) / 4, цена только Lite 0,0002 ₽; ответ — из data.js.
- 06: выбранные файлы показываются миниатюрами, но после отправки не сохраняются (ссылки createObjectURL живут только на странице) — у поста в очереди градиентная миниатюра.
- 06: «Черновик» попадает в очередь во вкладку «На паузе» с пометкой «черновик» (отдельного статуса в ТЗ нет); «Сразу» — в «Опубликовано» с toast «Демо: …».
- 06: «Куда» — только работающие аккаунты можно отметить, выключенные и с ошибкой видны серыми; по умолчанию отмечены все работающие.
- 06: после отправки toast показывается уже на странице очереди (sessionStorage seolit-toast).
- 07: обход 330 сочетаний (11 страниц × 5 размеров × 2 темы × 3 языка) и сквозные сценарии — скриптами Playwright, отчёт в QA.md; найденное исправлено (касание 44 px, цвета в токены, список на телефоне).

- 08a: разделы этапа 2 — отдельные страницы (balance.html, templates.html…) на общей оболочке; пока раздел не готов, на нём заглушка. Новости — в меню под «Помощью».
- 08l (по замечанию владельца): «Настройки» в меню строки открывают окно настроек приёмника с вкладками «Основные / Дополнительно / Шаблоны» — пункты «Дополнительно» как в реальном кабинете (Instant View, ссылка, UTM, сокращение, без звука, автокартинки, обложки, постинг изображений и видео); у источника — название, чтение, интервал.
- 08l: «Статистика», «Доступ», «Настройки» — вкладки внутри проекта (?tab=stats|access|settings): график по дням с выбором периода и рядов, CSV, по соцсетям; приглашение коллег с ролями; режим публикации (авто / ручная, как в реальном кабинете), часовой пояс, продление с баланса, удаление проекта.
- 08b: баланс — пополнение (сумма, быстрые суммы, карта / СБП / счёт для юрлица с проверкой ИНН, промокод — toast), деньги в демо реально зачисляются и видны в меню; «Хватит примерно на N месяцев» считается: баланс / (800 ₽ × оплаченные свои проекты). Комиссий не указываю — их нет в фактах.
- 08g: рефералы — ссылка и промокод с копированием, тексты для рассылки, «Поделиться» в Telegram/ВК, приглашённые, перевод начислений на баланс; процент программы не указываю — ссылка на условия на seolit.ru.
- 08h: API — ключи: создать (случайный), показать/скрыть, копировать, отозвать с подтверждением; методов API не выдумываю — ссылка на документацию на seolit.ru.
- 08i: RSS-тест — проверка по адресу (в демо — пример ответа), разбор вставленного XML настоящим DOMParser, проверки (даты, картинки, ссылки, текст), «Подключить как источник» в выбранный проект.
- 08c: расписания — список с мини-картой недели, сетка 7 × 24 красится мышью и пальцем (pointer-события, `touch-action: none` только на сетке), с клавиатуры — Enter/пробел по клетке; пресеты, лимит в сутки, пауза между постами, «Назначить аккаунтам» (пишет в настройки приёмника — видно в окне настроек). Клетки на телефоне ~13 px: исключение из правила 44 px, есть клавиатурная альтернатива и пресеты.
- 08d: шаблоны — переменные #TITLE#, #TEXT#, #URL#, #TAGS# вставляются в позицию курсора, соцсети, обрезка по словам с «…», живой предпросмотр на примере поста, «не сохранено», копия, отмена, удаление (аккаунты возвращаются к шаблону проекта).
- 08e: водяные знаки — знак (текст / логотип SEOlit / своя PNG) перетаскивается по примеру мышью и пальцем (pointer capture, `touch-action: none` только на знаке), стрелками с клавиатуры; размер, прозрачность, цвет, 9 позиций, свой фон-пример; «Скачать пример» рисует PNG на canvas. Загруженные картинки живут до перезагрузки (createObjectURL).
- 08f: автокартинки — превью на canvas из заголовка (перенос по словам, фон, выравнивание, размер, логотип и сайт), форматы 1:1 / 16:9 / 9:16, скачивание PNG.
- 08j: помощь — вопросы и ответы только по фактам (цены, подключение, расписания, шаблоны, ИИ-соавтор, Битрикс24), поиск, ссылки на инструкцию, прайс, контакты seolit.ru, форма в поддержку (toast). Новости — 4 реальные новости, «новое» до прочтения, ссылки на блог.
- 08k: профиль — email, смена пароля (toast), язык и тема меняются сразу (общие ключи с лендингом), часовой пояс, уведомления и каналы (почта / Telegram).
