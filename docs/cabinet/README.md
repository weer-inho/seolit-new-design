# Демо кабинета SEOlit

Кликабельный макет нового интерфейса для авторизованного пользователя. Живёт в папке `app/` этого же репозитория и публикуется на GitHub Pages вместе с лендингом:

| Что | Адрес после публикации |
|---|---|
| Лендинг | https://weer-inho.github.io/seolit-new-design/ |
| Вход в демо | https://weer-inho.github.io/seolit-new-design/app/login.html |
| Регистрация | https://weer-inho.github.io/seolit-new-design/app/register.html |
| Проекты | https://weer-inho.github.io/seolit-new-design/app/projects.html |

| Очередь | https://weer-inho.github.io/seolit-new-design/app/queue.html |
| Новый пост | https://weer-inho.github.io/seolit-new-design/app/post.html |

**Это не настоящий SEOlit.** Ни сервера, ни базы, ни настоящего входа. Статичные HTML/CSS/JS, вымышленные данные, всё «работает» только в браузере посетителя. Задача — чтобы в демо можно было потыкать с телефона или компьютера, на трёх языках (RU · EN · KZ) и в двух темах, и это ощущалось как настоящий интерфейс.

## Порядок работы
1. Промпты `prompts/01…07` — по одному за раз, в режиме плана (Shift+Tab).
2. После каждого — открыть страницу в браузере (PhpStorm → правый клик по файлу → Open In → Browser), проверить по списку «Как проверить» в промпте.
3. Коммит → `git push` → через минуту изменения на GitHub Pages.

## Ещё не нарисовано
Баланс, расписания, шаблоны, водяные знаки, автокартинки, рефералы, API, RSS-тест, помощь, настройки профиля. В демо они пока ведут на страницу-заглушку `app/soon.html`. Когда появятся макеты — промпт `prompts/08-next-screens.md`.
