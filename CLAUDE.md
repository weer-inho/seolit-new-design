# CLAUDE.md — лендинг SEOlit

Инструкции для Claude Code при работе с этим репозиторием.

## Что это
Одностраничный лендинг сервиса автопостинга SEOlit (seolit.ru). Статичный сайт для GitHub Pages:
без сборки, без фреймворков, без npm-зависимостей. Не добавляй бандлеры, React, Tailwind и т.п.

## Документация
Перед любой задачей прочитай `docs/SPEC.md` — там описано, как каждый экран должен выглядеть и двигаться (тайминги, телефон, reduced-motion).
- `docs/ISSUES.md` — известные проблемы и их причины.
- `docs/design/` — макеты (HTML + PNG). Это референс: цвета переводи в токены, разметку не копируй.
- `docs/prompts/` — очередь задач. Выполнив задачу, отметь её статус в SPEC.md/ISSUES.md в том же коммите.

## Структура
- `index.html` — вся разметка. Экраны — `<section class="scr" id="…">` в `<main>`, по порядку:
  `hero` (живое слово + доска контент-плана), `auto` (автопостинг),
  `cross` (песочница «поймай и кинь»), `how` (выбор источника), `price` (калькулятор),
  `schedule` (график лимита), `ai` (ИИ-соавтор, тёмный в обеих темах, токены `--ai-*`), `bitrix` (3D-слои), `start` (CTA + сфера соцсетей + конфетти + подвал).
- `css/style.css` — все стили. Сверху токены цвета в `:root` и два тёмных блока.
- `js/main.js` — весь интерактив, один IIFE. Каждый экран — отдельная функция-модуль с комментарием-заголовком.
- `favicon.svg`, `.nojekyll` (отключает Jekyll на GitHub Pages).

## Правила
- **Цвета только через токены** (`--bg`, `--surface`, `--fg`, `--muted`, `--line`, `--soft`, `--accent`, `--atext`, `--mint`, `--coral`, `--amber`, `--t-*`).
  Новый токен добавляй во все три места: `:root`, `@media (prefers-color-scheme: dark) :root:not([data-theme="light"])`, `:root[data-theme="dark"]`.
- **Тема**: кнопка `#themeBtn` ставит `data-theme` на `<html>` и пишет `localStorage['seolit-theme']`.
- **Шрифты**: заголовки экранов — Unbounded (`--font-d`), текст и заголовок hero — Manrope (`--font-b`). Подключены с Google Fonts.
- **Анимации**: один `requestAnimationFrame`-цикл внизу `main.js`. Модуль регистрируется через `watch(el, { tick(dt) {…} })` и тикает только когда элемент виден.
  Для canvas — `regCanvas(canvas)` (учитывает плотность пикселей и ресайз).
- **Параллакс**: атрибут `data-speed="0.2"` на элементе. Сдвиг идёт через CSS-свойство `translate`, поэтому не конфликтует с `transform`-анимациями.
- **Уменьшение движения** (`prefers-reduced-motion`): два флага в `main.js`. `still` — крупного движения нет
  (вращения, полёты, конфетти, магнит, перелёт; параллакс ×0,5, бегущие строки вдвое медленнее). `fade` — смена состояний остаётся, но проявлением на месте
  (`fadeIn(el)`, `FADE` = 350 мс). Сайт при этом не замирает. В CSS блок reduce в конце файла: движущие анимации — `none`,
  остальные — их opacity-версии (`fadeIn`, `rvFade`…). Новая автоанимация должна учитывать оба флага.
- **Прокрутка**: пошаговая, модуль `pager` в `main.js` (колесо, свайп, клавиши, ссылки на `#экран`). Новый элемент, который
  тянут пальцем или мышью, добавь в селекторы `GRAB` / `NO_TOUCH`, иначе жест уйдёт в листание.
- **Телефоны**: проверяй на ширине 390px. Брейкпоинты в конце CSS: 1080, 900, 700, 520px. Горизонтальной прокрутки быть не должно.
  Перетаскивание на тач-экранах: `touch-action: none` только на перетаскиваемых элементах, а контейнеру — `pan-y`, чтобы страница листалась.
- **Логотип**: вариант A (узел «один → много»), SVG-символы `#logo` и `#mark` в начале `index.html`.
- **Соцсети**: массив `NETS` в начале `main.js` (подпись, название, цвет) и `ICONS` (SVG-path значков, viewBox 24×24).
  Значки рисуем белыми на цветной плашке: `icon(s)` в JS; плашки из разметки (`.chip`, `.deco--chip > i`) с подписью из `NETS`
  получают значок автоматически. Значок — только белый знак без своей подложки. Источники: Simple Icons (CC0), CoreUI Brands (CC0), Boxicons (MIT),
  LinkedIn — Remix Icon (Apache-2.0), «Мой Мир» — знак Mail.ru. Значок с другим viewBox пиши объектом `{ v, d }`.
  Нового значка нет в этих наборах — ищи в других открытых (Iconify), лицензию пиши в комментарии у `ICONS`.
- **Тексты** — на русском, по фактам с seolit.ru. Цифры и функции не выдумывать.
- Комментарии в коде — на русском, коротко.

## Локальный запуск
```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```
Без Python: открыть `index.html` прямо в браузере (двойной клик) или через PhpStorm → Open In → Browser — всё работает и с `file://`.

## Публикация на GitHub Pages
Settings → Pages → Build and deployment → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
Все пути относительные, поэтому сайт работает и по адресу `https://<логин>.github.io/<репозиторий>/`.
