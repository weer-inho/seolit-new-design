# Лендинг SEOlit

Живой одностраничный лендинг сервиса автопостинга [SEOlit](https://seolit.ru/).
Статичный сайт без сборки: `index.html`, `css/style.css`, `js/main.js`.

## Запуск локально
```bash
python3 -m http.server 8000
```
Откройте http://localhost:8000. Можно и просто открыть `index.html` в браузере.

## Публикация на GitHub Pages
1. Создайте репозиторий на GitHub и отправьте в него этот проект:
   ```bash
   git remote add origin https://github.com/<логин>/<репозиторий>.git
   git push -u origin main
   ```
   Или загрузите файлы через веб-интерфейс: Add file → Upload files.
2. Settings → Pages → Build and deployment → Source: «Deploy from a branch», ветка `main`, папка `/ (root)` → Save.
3. Через минуту-две сайт откроется по адресу `https://<логин>.github.io/<репозиторий>/`.

Файл `.nojekyll` отключает обработку Jekyll — сайт отдаётся как есть.

## Экраны
1. **Hero**: слово в плашке меняется само («сразу / по расписанию / без копипаста / с адаптацией»), доска контент-плана — карточки переезжают по колонкам, кнопка «+ Пост» добавляет свою. Внизу бегущая строка соцсетей.
2. **12 соцсетей**: 3D-орбита, крутится сама и пальцем/мышью; по нажатию в соцсеть летит пост.
3. **Автопостинг**: публикация с сайта разлетается по ленте.
4. **Песочница**: соцсети можно ловить и кидать в SEOlit, цена остаётся 800 ₽.
5. **Это очень просто**: выбор источника материалов, текст печатается.
6. **Цена**: калькулятор дополнительных аккаунтов, 3D-карточка, бегущие строки возможностей.
7. **Расписание**: живой график лимита постов в час.
8. **Битрикс24**: 3D-куб.
9. **Старт**: искры за курсором, конфетти, подвал.

Тёмная тема — из системы или по кнопке в шапке. При «уменьшении движения» автоанимации останавливаются.

## Перед запуском заменить
- `href="#"` у «Вход», «Мы в Битрикс24» и ссылок подвала.
- Кнопку «Начать работу» связать с регистрацией.
